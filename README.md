# white_bg_removal

Dudych BG Removal is a fast, free, and dynamic online tool designed to help you remove white backgrounds from your images instantly.

Features

Dynamic Removal: Adjust sensitivity settings in real-time to precisely target and remove white or off-white backgrounds.

Client-Side Processing: No image data is uploaded to a server; all processing happens directly in your browser for maximum privacy and speed.

Fast Download: Export your processed image as a clean, transparent PNG.

Responsive Design: Works seamlessly on desktop and mobile devices.

How to Use

Upload: Click the "Upload Image" button and select an image from your device.

Adjust: Use the Sensitivity slider to fine-tune how much of the light background you wish to remove.

Download: Once satisfied with the preview, click "Download PNG" to save your transparent image.

Technology

Built with HTML5, CSS3 (Tailwind CSS), and the Canvas API.
